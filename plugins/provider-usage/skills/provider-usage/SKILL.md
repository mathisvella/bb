---
name: provider-usage
description: Inspect and configure provider usage sources and visibility.
---

Use `bb plugin config provider-usage set showCursor true` to show Cursor usage,
or `false` to hide it. Cursor is hidden by default. This affects the usage card,
usage page and usage RPC output without disabling the agent.

Pooled accounts appear under Account Pooler; local accounts appear under their machine.
Select the relevant location before inspecting missing accounts.
